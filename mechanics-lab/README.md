# Statics Study Lab

Buildless, responsive Exam 1 prototype. Open `dist/index.html` in a modern browser, or serve `dist` with any static HTTP server. Native MathML renders fractions and other mathematics without a runtime dependency. Google Fonts are optional; system fonts are the fallback.

Includes a 2D force playground, component solutions, original guided practice, a printable force equation sheet, and a TI-84-style scientific calculator. This is not TI firmware. Practice completion stays in browser-local storage; it does not sync between devices. Textbook questions/answers and moment lessons are not yet included.

Run `node check.cjs`, `node --check dist/app.js`, and `node --check dist/math.js` for numerical and syntax checks.
